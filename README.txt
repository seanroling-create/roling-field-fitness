ROLING FIELD FITNESS — PHONE WEB APP

This is an installable Progressive Web App (PWA), not a native App Store / Play Store application.

SETUP
1. Upload ALL files in this folder to an HTTPS static website (for example GitHub Pages, Netlify, Cloudflare Pages).
2. Visit the resulting HTTPS address in Safari on iPhone or Chrome on Android.
3. iPhone: Share > Add to Home Screen. Android: browser menu > Install app / Add to Home Screen.
4. Launch from the ROLING symbol. After the first successful online load, workout content works offline.

FEATURES
- Complete 40-session eight-week plan transcribed from the finalized PDF.
- Exercise descriptions and YouTube SEARCH links for relevant exercise demos. These are not curated/verified individual videos.
- Per-exercise weight entry, plus additional per-set entries.
- Automatically computed highest logged training weight for each exercise.
- AFT event record entry and automatic best result selection.
- Stopwatch, countdown, presets, vibration alert where supported.
- Session completion and notes, guidance, export/import JSON backups.

IMPORTANT LIMITATIONS
- All data is saved in the browser's localStorage; export backups frequently.
- This app does not sync across devices and is not currently deployed/hosted.
- The weight tracker identifies exercises by the text of each prescription. Some compound sets may need manually labeling in session notes.
- The timer runs while the app is open. Background restrictions on mobile browsers can affect alert/vibration behavior.
- For official AFT testing, consult current Army instructions and approved equipment.
